# RarePart Finder

เว็บตลาดซื้อขายอะไหล่รถยนต์หายาก (HTML + JavaScript + Supabase)

## ฟีเจอร์
- สมัครสมาชิก / เข้าสู่ระบบด้วย Supabase Auth
- ลงขายสินค้า (รูป ราคา หมวดแบรนด์ รายละเอียด สต็อก), แก้ไข, ลบ
- ค้นหา กรองตามแบรนด์/หมวด ดูรายละเอียดสินค้า
- ตะกร้าและสั่งซื้อ (คิดราคา ตัดสต็อกฝั่งเซิร์ฟเวอร์)
- ผู้ซื้อดูประวัติคำสั่งซื้อ, ผู้ขายดูออเดอร์ที่เข้ามา

## ไฟล์
| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าแรก รายการสินค้า |
| `product.html` | รายละเอียดสินค้า |
| `add-product.html` / `edit-product.html` | ลงขาย / แก้ไขสินค้า |
| `checkout.html` | ตะกร้าและยืนยันสั่งซื้อ |
| `profile.html` | โปรไฟล์ ประวัติสั่งซื้อ สินค้าของฉัน |
| `seller-orders.html` | ออเดอร์ฝั่งผู้ขาย |
| `login.html` / `register.html` | เข้าสู่ระบบ / สมัครสมาชิก |
| `common.js` | Supabase client, ตะกร้า, ฟังก์ชันร่วม |
| `schema.sql`, `schema2.sql` | โครงสร้างฐานข้อมูลและกฎความปลอดภัย (RLS) |

## ติดตั้ง
1. สร้างโปรเจกต์ Supabase และ bucket `product-images` (Public)
2. รัน `schema.sql` แล้วรัน `schema2.sql` ใน SQL Editor
3. ใส่ URL และ anon key ของโปรเจกต์ใน `common.js`
4. เปิดไฟล์ผ่านเว็บเซิร์ฟเวอร์หรือ GitHub Pages

> anon key เปิดเผยในโค้ดได้ แต่ความปลอดภัยขึ้นกับ RLS ใน `schema.sql` / `schema2.sql` ห้ามใส่ service_role key ในเว็บเด็ดขาด

## ที่ยังไม่มี
การชำระเงินจริง, การแจ้งเตือนผู้ขาย, การอัปเดตสถานะออเดอร์
